#질문
메뉴 화면 구현
터레인 툴의 여러 기법을 하나씩 구현 예정
기법을 선택할 메뉴 화면 구현
화면 내의 텍스트는 하얀색(파란 배경이니까)
메뉴 화면의 오른쪽 상단에 종료 버튼 클릭 또는 메뉴 화면에서 ESC 입력 시 프로그램 종료
메뉴 최상단에 제목 텍스트 "===Terrain Showcase System==="
이후 기법이 추가될 때마다 제목 텍스트 아래에 "n. 기법명 (영어 기법명)" 형식으로 추가될 예정
텍스트 위치는 중앙 정렬
기법명 텍스트를 클릭하면 그 기법이 구현된 화면으로 이동
기법 왼쪽 상단 돌아가기 버튼("돌아가기" 텍스트) 클릭, 또는 ESC 입력 시 메뉴 화면으로 이동
메뉴 화면 테스트용 기법 구현 화면인 "0.메뉴 구현 테스트" 추가 (아무것도 구현되지않은 빈 기법 구현 화면)
